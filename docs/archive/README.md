# 历史归档

这里保存早期研究、旧实现规格、实验和演示记录。它们不是当前功能清单，也不是部署步骤。
当前范围以 [文档索引](../README.md)、[根规格](../../SPEC.md) 和 [Workflow](../IMPROVEMENT_WORKFLOW.md) 为准。

- 根目录：早期技术选择、Memory / RSI 探索、后端研究和实验记录。
- `specs/`：旧工作台、可靠性引擎和技术选型方案。
- `design/`：历史工程记忆设计与配图。
- `acceptance/`：当时版本的 MVP / Runtime 验收。
- `showcase/`：旧演示与文章材料。

保留这些记录以便核查历史结论。新行为不再同步修改旧规格，新的实验也不覆盖原始结果。
